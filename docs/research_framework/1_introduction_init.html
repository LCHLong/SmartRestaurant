1. Chọn framework nhanh trước khi học sâu

Trả lời câu hỏi bên trái, cột phải gợi ý framework nên học trước — giúp bạn không phải học cả 3 kỹ như nhau.

Bài toán cần AI hiện hình / avatar cùng lúc với giọng nói?
TEN Framework Mạnh nhất về xử lý đa phương tiện (voice + video + avatar)
Cần nhiều người dùng nói chuyện với AI cùng lúc, ở quy mô lớn?
LiveKit Agents Hạ tầng WebRTC bền vững, có sẵn dịch vụ đám mây quản lý
Chỉ cần build nhanh, tự triển khai, không muốn phụ thuộc hãng nào?
Pipecat Nhẹ, khởi động nhanh, dễ tự host
Chưa chắc bài toán cụ thể, chỉ muốn học 1 framework để hiểu chung?
Pipecat hoặc LiveKit Tài liệu và cộng đồng lớn nhất, ít rủi ro bị kẹt khi tự học

2. Pipecat — bắt đầu trong ~15 phút

Pipecat
Ngôn ngữ: Python Cần cài: uv (trình quản lý gói Python) Chạy ở đâu: máy cá nhân
Bước 1 — Cài công cụ dòng lệnh ~2 phút
curl -LsSf https://astral.sh/uv/install.sh | sh
uv tool install "pipecat-ai[cli]"
Bước 2 — Tạo dự án mới ~2 phút
pipecat init
# Công cụ sẽ hỏi bạn muốn tạo bot dạng điện thoại hay web/mobile
Bước 3 — Chạy thử bot đầu tiên ~5 phút
cd ten-du-an-vua-tao
uv run bot.py
# Mở trình duyệt theo link được in ra để nói chuyện với bot
Cấu trúc code cốt lõi cần nhìn ra
pipeline = Pipeline([
    transport.input(),   # nhận âm thanh vào
    stt,                 # giọng nói → chữ
    llm,                 # chữ → suy nghĩ → chữ trả lời
    tts,                 # chữ trả lời → giọng nói
    transport.output(),  # phát âm thanh ra
])

→ docs.pipecat.ai

3. LiveKit Agents — bắt đầu trong ~10 phút

LiveKit Agents
Ngôn ngữ: Python hoặc Node.js Cần cài: pip, tài khoản LiveKit Cloud (miễn phí) Chạy ở đâu: terminal máy cá nhân, kết nối cloud
Bước 1 — Cài thư viện ~2 phút
pip install "livekit-agents[openai,deepgram,cartesia]"
Bước 2 — Cấu hình khóa API ~3 phút
cp .env.example .env.local
# Điền LIVEKIT_URL, LIVEKIT_API_KEY, LIVEKIT_API_SECRET
# lấy từ tài khoản LiveKit Cloud (miễn phí đăng ký)
Bước 3 — Chạy thử trong terminal ~3 phút
python3 agent.py console
Cấu trúc code cốt lõi cần nhìn ra
session = AgentSession(
    stt=inference.STT("deepgram/nova-3"),   # tai nghe
    llm=inference.LLM("openai/gpt-4o"),     # bộ não
    tts=inference.TTS("cartesia/sonic-3"),  # giọng nói
)
await session.start(room=ctx.room, agent=Agent(
    instructions="Bạn là trợ lý giọng nói hữu ích."
))

→ docs.livekit.io/agents/start/voice-ai

4. TEN Framework — bắt đầu trong ~30 phút

TEN Framework
Ngôn ngữ: đa ngôn ngữ (chạy qua Docker) Cần cài: Docker, pnpm Chạy ở đâu: Docker container, hoặc GitHub Codespaces (không cần cài gì)

Lưu ý: TEN cần nhiều bước cài đặt hơn 2 framework kia. Nếu muốn thử nhanh không cài gì trên máy, dùng GitHub Codespaces (bước có đánh dấu *).

Bước 1 — Lấy mã nguồn & cấu hình ~5 phút
git clone https://github.com/TEN-framework/ten-framework.git
cd ten-framework
cp .env.example .env
# Mở file .env, điền API key cho LLM / STT / TTS bạn muốn dùng thử
Bước 2 — Build và chạy server ~10-15 phút
docker compose up
task use
task run
Bước 3 — Mở giao diện thử nghiệm ~2 phút
# Mở trình duyệt tại
http://localhost:3000
*Cách thử không cần cài gì (GitHub Codespaces)
# Vào repo TEN-framework trên GitHub → nút "Code"
# → "Create codespace on main" → làm theo hướng dẫn trong VSCode trình duyệt

→ github.com/TEN-framework/ten-framework

6. Checklist rút gọn — 90 phút thay vì 4 giờ

Nếu thời gian rất eo hẹp, chỉ cần làm đủ các mục sau (không cần đọc lại lý thuyết dài dòng).

  • Dùng bảng ở mục 1 để chọn ra 1 framework ưu tiên học sâu
  • Chạy xong quickstart của framework ưu tiên (mục 2, 3 hoặc 4) — có bot chạy được là đạt
  • Đọc đoạn "Cấu trúc code cốt lõi" của framework đó, hiểu 3 dòng STT / LLM / TTS làm gì
  • Lướt bảng so sánh ở mục 5 để biết 2 framework còn lại khác gì, phòng khi cần đổi hướng sau này
  • Ghi 2–3 câu kết luận: chọn framework nào, vì lý do gì
